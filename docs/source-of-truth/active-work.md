# Rencana Kerja Aktif

Tidak ada pekerjaan aktif.

GitHub Issues adalah sumber status pekerjaan yang sedang berjalan. Jika sebuah pekerjaan lintas-file memerlukan konteks khusus agen, letakkan ringkasan rencana di sini dan tautkan Issue terkait; jangan salin backlog. Hapus atau ganti rencana lama saat selesai. Ikuti [panduan kerja solo developer bersama agen AI](panduan-kerja-solo-developer-dengan-agen.md).
