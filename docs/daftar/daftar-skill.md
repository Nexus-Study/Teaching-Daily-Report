# Daftar Skill

Katalog ini mencatat skill desain yang dapat membantu pekerjaan UI. Skill adalah alat bantu opsional: gunakan hanya jika tersedia di sesi Copilot, periksa instruksi dan dampaknya sebelum menerapkannya, dan tetap ikuti aturan proyek.

## Skill yang relevan untuk kualitas UI

- [Anti-Slop Design](https://github.com/wwewtech/anti-slop-design/tree/main) — panduan untuk menghindari pola antarmuka generik dan meningkatkan kualitas desain.
- [Taste Skill](https://github.com/Leonxlnx/taste-skill/tree/main) — skill desain frontend; tercatat sudah dipasang pada lingkungan pengguna, tetapi ketersediaannya untuk setiap sesi atau anggota tim tidak dijamin.
- [Penpot UI/UX Design](https://github.com/github/awesome-copilot/tree/main/skills/penpot-uiux-design) — skill UI/UX dalam koleksi Awesome Copilot.

## Katalog skill lain

- [Gesso Skills](https://github.com/Gesso-Build/skills/tree/main) — koleksi skill yang dapat ditinjau untuk kebutuhan proyek.
- [Awesome Copilot](https://github.com/github/awesome-copilot) — katalog prompt, instruksi, dan skill Copilot.

Keberadaan tautan di daftar ini tidak memasang atau mengaktifkan skill secara otomatis. Untuk aturan UI yang berlaku di repository ini, ikuti [instruksi kualitas UI Copilot](../../.github/instructions/ui-design.instructions.md) dan [website rujukan desain](./daftar-website-rujukan.md).
